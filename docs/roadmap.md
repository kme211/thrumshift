# Phase 2

Goal:

Expand the station while preserving the core gameplay loop.

Potential work:

- Station navigation
- Multiple subsystem rooms
- Additional repair activities
- Environmental storytelling
- Expanded station map
- Improved ambient audio
- Save/resume improvements

# Phase 3

Goal:

Grow the station into a larger experience.

- Multiple missions
- Narrative progression
- Persistent station state

- Unlockable station areas
- Additional telemetry systems

Ideas currently outside the planned roadmap.

- Cooperative multiplayer
- Multiple operator roles
- Shared station maintenance
